Submission Requirements

Please make sure your submission:

  • Contains accurate application information.
  • Uses working URLs for the application icon and download.
  • Contains a clear and useful description.
  • Does not contain malicious or harmful software.
  • Does not impersonate another developer or application.
  • Is ready for review before being submitted.

Applications are manually reviewed by GDC administrators.
