                    AU FLOOD TELEMETRY & SURVEILLANCE SYSTEM                    
================================================================================
Project Leader   : Rahmiel B. Baldovino
Adviser          : Sir Jobert Mandigma
Monitoring Gates : Donada Gate & Taft Gate (AU - Mabini Campus)

--------------------------------------------------------------------------------
1. HARDWARE SPECIFICATIONS & PINOUT
--------------------------------------------------------------------------------
* Microcontroller : Dual ESP32 Nodes (Donada Gate Node & Taft Gate Node)
* Edge Gateway    : Raspberry Pi 4 (Hosts OpenCV RTSP-to-MJPEG Proxy & web.html)
* Power Delivery  : 5V DC via USB-C (ESP32 / RPi4); 12V DC (IP CCTV Cameras)

SENSOR CONNECTIONS (Identical for Donada & Taft ESP32s):
- JSN-SR04T (Waterproof Ultrasonic Depth Sensor):
    * VCC  -> 5V (VIN)
    * GND  -> GND
    * TRIG -> GPIO 5
    * ECHO -> GPIO 18 (via 1k/2k ohm voltage divider to step down to 3.3V)
- DHT11 (Temperature & Relative Humidity):
    * VCC  -> 3.3V
    * GND  -> GND
    * DATA -> GPIO 4 (with 10k ohm pull-up to 3.3V)
- BH1750 (Ambient Illuminance / Light Sensor - I2C):
    * VCC  -> 3.3V
    * GND  -> GND
    * SCL  -> GPIO 22
    * SDA  -> GPIO 21
    * ADDR -> GND (Address: 0x23)

--------------------------------------------------------------------------------
2. THINGSPEAK CLOUD CHANNEL MAP (Channel ID: 3482463)
--------------------------------------------------------------------------------
Field 1 : Donada Gate - Water Depth (cm)
Field 2 : Donada Gate - Temperature (degC)
Field 3 : Donada Gate - Relative Humidity (%)
Field 4 : Donada Gate - Ambient Light (Lux)
Field 5 : Taft Gate   - Water Depth (cm)
Field 6 : Taft Gate   - Temperature (degC)
Field 7 : Taft Gate   - Relative Humidity (%)
Field 8 : Taft Gate   - Ambient Light (Lux)
* Ingestion Interval: 20 s (free tier)

--------------------------------------------------------------------------------
3. SAFETY & VEHICLE PASSABILITY THRESHOLDS
--------------------------------------------------------------------------------
* Depth < 20 cm      : [ NORMAL ]        - Passable to all types of vehicles
* Depth 20 to 35 cm  : [ WARNING ]       - Not passable to light vehicles
* Depth > 35 cm      : [ CRITICAL ALARM] - Impassable to all vehicular traffic
