About Geek Devs Community

Geek Devs Community was created with the goal of bringing together people who enjoy creating software and exploring technology. The community focuses on practical development, experimentation, and innovation.

From application development to operating system customization, GDC covers a wide range of technical interests. Members are encouraged to share knowledge, contribute to projects, and help others improve their skills.

Our Mission

Building the future through development.

Our mission is to create a friendly environment where developers can:

- Learn programming and software development
- Collaborate on open-source projects
- Explore operating systems and technology
- Create useful applications and tools
- Preserve and improve classic software experiences

REIMP - Reimplementation Project

Reimplementation, research, and preservation.

REIMP focuses on recreating classic software experiences using modern development techniques.

The project explores how older software concepts, interfaces, and technologies can be redesigned for current platforms.

REIMP combines software engineering, user interface design, system development, and reverse engineering concepts to create modern alternatives inspired by classic software.

Why REIMP Exists

Many classic applications and experiences have disappeared over time. REIMP aims to preserve the ideas behind these technologies while adapting them for modern systems.

The project encourages developers to study how software works, learn from older designs, and create improved implementations.

About the Developer

Andrew Simson (RDCubing)

Geek Devs Community and the REIMP project are maintained by Andrew Simson, also known online as RDCubing.

The project began as a way to explore software development, Windows customization, and classic user interface design while building open-source applications and tools for the community.

Areas of interest include:

• Windows desktop development
• Reimplementing classic Windows experiences
• C#, C++, HTML, CSS, and JavaScript
• Open-source software and community projects
• User interface design inspired by classic operating systems

Frequently Asked Questions

What is Geek Devs Community?
GDC is a community for developers and technology enthusiasts.

Who can join?
Anyone interested in programming, technology, and software development.

What is REIMP?
REIMP is a project focused on recreating and improving classic software experiences.

What is NeonStore?
NeonStore is a developer-focused application store for discovering, showcasing, and downloading community-made software.

Does NeonStore use GDC accounts?
Yes. NeonStore currently uses the same unified account system used by supported GDC services.

How can I contribute?
Members can contribute through development, testing, documentation, ideas, and community support.
